# Gas LP Quiroz Metepec - Sitio Web Oficial

Sitio web oficial y landing page optimizada para **Gas LP Quiroz** en el municipio de Metepec, Estado de México. Ofrece información sobre recarga de tanques estacionarios, cilindros de gas, cobertura rápida en 20-35 minutos, y certificación PROFECO.

---

## 🛠️ Tecnologías Utilizadas

- **Estructura**: HTML5 semántico optimizado para SEO técnico.
- **Estilos**: CSS3 moderno con variables y animaciones nativas inspiradas en el diseño moderno de Elementor.
- **Interactividad**: JavaScript vanilla para control de animaciones al hacer scroll, acordeón FAQ y toggle de menú móvil.
- **Servidor**: Node.js con Express para servicio de archivos estáticos y redirecciones.

## 🚀 Instalación y Ejecución Local

Para ejecutar este proyecto en tu entorno local:

1. Asegúrate de tener instalado **Node.js** (versión 16 o superior).
2. Clona el repositorio e instala las dependencias necesarias:
   ```bash
   npm install
   ```
3. Inicia el servidor de desarrollo:
   ```bash
   npm start
   ```
4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador para visualizar el sitio.
